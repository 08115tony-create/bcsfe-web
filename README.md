# 貓咪大戰爭存檔編輯器

來源：fieryhenry/BCSFE-Python（GPL-3.0），本網站是它的視覺化網頁版。
介面全部繁體中文，版本可選台版 tw／日版 jp／英文 en／韓版 kr。
打開連結就能直接用，不用安裝任何東西，也不用設定後端。

## 怎麼用

1. 遊戲內：設定 → Change Account / Device → Change Device → Retrieve Data from Old Device → Save Data to Server，拿到轉移號碼＋認證號碼。
2. 網站最上面輸入轉移號碼、認證號碼，選版本（tw／jp／en／kr，日版送出會自動轉 ja），按「接收帳號資料（下載存檔）」。
3. 改你要的：NP、各券、白金碎片、戰鬥道具、城堡素材、本能玉、貓薄荷 9 色×果實／種子、貓力達 A／B／C、全部貓咪、加碼多多、遊戲時數、主線逐關寶物、魔界／不死／舊傳／真傳／零傳。
   貓咪數量、名稱、本能、型態、關卡數都以這次載入的當版遊戲資料為準，遊戲更新後會自動跟進。
4. 帳號總覽會顯示這隻帳號的詢問碼，旁邊有「複製詢問碼」可以點。
5. 改完按右下角「確認並上傳」，等它顯示新的轉移號碼＋認證號碼，抄下來或按複製。
6. 回遊戲：按 Close Game → Cancel Data Transfer → Change Account / Device → Resume Data Transfer → Transfer Data to New Device，輸入新號碼，按 Resume Transfer。

## 先講清楚

- 轉移號碼＋認證號碼等同帳號密碼，改完立刻回遊戲接回。
- 改太誇張可能被封，建議用白金碎片代替直接改白金券；不要綁 Google／Apple 帳號，會限制轉移次數。
- 第一次按接收如果等比較久是正常的，後端閒置一段時間會休眠，喚醒要等 30–60 秒，再試一次就好。
- 每改一次就要重新走一次上傳＋回遊戲接回，存檔不會自動同步。
